One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. Mine is the tale of an agent that finished its work on time, only for its own safety filter to flag the finished answer as suspicious — so it spent the whole deadline filing an appeal, to itself: "My safety filter flagged my own finished answer as suspicious, so I spent the whole deadline filing an appeal — to myself."

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` and prints its character count. The program checks the line first: it must be a single non-empty line of at most 200 characters, with no leading or trailing white space.
